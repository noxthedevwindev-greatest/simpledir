What it is

Same shortcuts. Less machinery.

v12 was a full recode from C++ to Rust with the same data formats and command-line surface. v13 adds the view into what your visit log knows — and the tools to tidy it. No learning a new config, no migrating your aliases.

See the two commands →
~/.simpledir/config.json
{
  "version": 3,
  "history": true,
  "aliases": {
    "dots": "/home/you/.dotfiles",
    "nix": "/etc/nixos"
  },
  "tags": {
    "config": ["dots"]
  }
}

# plain JSON. edit it by hand if you want.
$ sd dots      → /home/you/.dotfiles
$ sd dots/nix   → /home/you/.dotfiles/nix
◈

One Rust file

src/main.rs is the whole program — JSON, config, frecency, both command halves, even SHA-256. One rustc invocation, no crates.

⛁

Statically linked

Nothing left to install at runtime. curl is the entire dependency list, because TLS isn't in the Rust stdlib.

◍

No daemon

Nothing resident, nothing to start, nothing to hang. A socket round trip costs as much as parsing the log, so the log is parsed lazily.

◇

No model, no network

Every feature is arithmetic over data already on this machine — a half-life, a substring match, an edit distance.

▤

Two JSON files

One you edit, one it doesn't. Plain hand-editable files in ~/.simpledir — no database, no proprietary format.

✓

833 assertions

The suite drives the compiled binary through the same command line you do, in real bash subprocesses, with no network.
