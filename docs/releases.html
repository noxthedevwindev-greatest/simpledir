v14.0.0 — cleaner edges, safer jumps.

One feature set per release, so the notes are a list of what a user can now do. Stable releases ship freely; prereleases are for features whose shape is still changing.

Current stable

Fewer surprises,
same tiny tool.

v14 is a hardening release. Non-ASCII paths survive a config round trip, a literal $HOME in a stored path stays literal, ambiguous shortcuts never fall through to frecency, and downloads and updates check what they publish before touching anything. Aliases and data formats are unchanged.

Open the releaseInstall it

What's in v14

Unicode-safe config

Aliases and paths with non-ASCII characters round-trip without mojibake; trailing junk and malformed \u escapes are rejected.

Predictable matching

A literal $HOME in a stored path stays literal, and an ambiguous prefix says so instead of jumping to a frecency hit.

Honest flags

Unknown flags and a bad --top N exit 2. Update skips prereleases and treats a malformed published checksum as fatal.

Safer swaps

Update backups and revert are atomic and leave the binary executable; a missing checksum still only warns.

Complete docs

Every sd and sdcfg verb is documented on the site, including the flags that save you a typo.

Measured floor

sdcfg bench measures sd --version before and after the cases, so the "over startup" column stays honest.
